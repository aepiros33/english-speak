# 영어 회화 연습 앱 — 제품 요구사항 문서 (PRD)

이 문서는 다른 Grok/에이전트가 기획·디자인·구현을 진행할 때 단일 소스로 쓰라고 작성했다.  
모호하면 이 문서의 **결정된 원칙**을 따르고, 막히면 문서 하단 **미결정 사항**만 사용자에게 물어라.

- 문서 버전: 1.1 (2026-09-25 — 개인용 적용. 변경 내용은 맨 아래 **20. 개인용 적용 메모** 참고)
- 이전 버전: 1.0 (원본)
- 작성 기준: 영어 회화 학습 효과 연구 요약 + 사용자 요청
- 제품 언어: UI 한국어 / 학습 콘텐츠 영어
- 1차 타깃: 한국 성인, 읽기는 되지만 말이 안 나오는 A2–B2

---

## 0. 에이전트용 작업 지시

### 역할
너는 이 앱의 프로덕트 오너 + 디자이너 + 개발 리드 역할을 한다.

### 작업 순서
1. 이 PRD를 기준으로 MVP 범위만 구현한다. P2는 구현하지 마라.
2. 화면은 7개 핵심 스크린을 벗어나지 마라.
3. 카피·온보딩·피드백 문구는 한국어로 작성한다.
4. “콘텐츠를 많이 보여주는 앱”이 아니라 **입을 열고 → 교정받고 → 다시 말하는 앱**으로 만든다.
5. 구현 전 가정이 필요하면 이 문서 가정표를 사용하고, 없는 기술 스택은 현실적인 기본값을 고른 뒤 명시하라.

### 하지 말 것
- 토익 RC/LC 문제은행
- 장문 문법 강의
- 영상 시청이 메인인 콘텐츠 앱
- 원어민 억양 완성을 약속하는 카피
- MVP에 커뮤니티 피드, 튜터 마켓, 언어교환 매칭
- 모든 문법 오류를 빨간펜으로 고치기
- AI가 대충 “좋아요”만 하는 피드백

## 1. 제품 개요

### 한 줄
한국인 학습자가 하루 15–30분, 혼자 말해도 교정까지 받는 루틴을 유지하게 해서 4–6주 안에 “말이 나온다”는 체감을 만드는 앱.

### 문제
- 듣기·읽기는 되는데 말이 안 나온다.
- 말할 상대가 없고, 틀리기 부끄럽다.
- 무엇을 연습해야 하는지 모른다.
- 콘텐츠만 보기만 하면 실력이 는 줄 안다.
- 교정 없이 말하면 같은 실수를 반복한다.

### 해결
고정된 데일리 루틴:

1. 쉐도잉 (리듬·발음)
2. 출력 과제 (독백 또는 롤플레이)
3. 피드백 최대 3개
4. 고친 문장 다시 말하기
5. 오늘 막힌 청크 3개 저장 후 분산 복습

### 성공의 정의
사용자가 버튼을 많이 누르는 것이 아니라, **실제로 말한 시간**과 **다시 말하기를 완료한 세션 수**가 늘어나는 것.

---

## 2. 결정된 원칙 (변경하지 말 것)

1. 입력만 주지 않는다. 매 세션에 반드시 출력이 있다.
2. 단어 암기가 기본이 아니다. 학습 단위는 **청크(구문)** 다.
3. 피드백 없는 말하기는 실수 연습이다. 교정 후 재발화가 세션 완료 조건이다.
4. 한 세션 교정은 최대 3개. 의사소통을 방해하는 것만 고친다.
5. 하루 15–30분이 기본. 주말 몰아치기 UX를 설계하지 않는다.
6. 불안을 먼저 낮춘다. 초반 과제는 혼자/짧은 스크립트부터.
7. AI 대화는 워밍업이다. 오해를 그냥 넘겨서는 안 된다. 이해 안 되면 다시 묻는다 (repair).
8. 칭찬만 하지 않는다. 구체적 한 줄 + 고친 예문 + 따라 말하기.
9. “원어민처럼”이 목표가 아니다. “상대가 한 번에 알아듣는 말”이 목표다.
10. 온보딩이 끝나기 전에 사용자가 한 번은 말하게 한다.

## 4. 목표 / 비목표

### 목표 (v1)
- 매일 짧게 말하게 만든다.
- 쉐도잉으로 발음·리듬을 훈련한다.
- 즉흥 발화(롤플레이/독백)를 훈련한다.
- 청크를 꺼내 쓰게 한다.
- 오류를 짚고 고친 문장을 다시 말린다.
- 4주 전후 녹음을 비교할 수 있게 한다.

### 비목표 (v1에서 명시적으로 제외)
- 토익 듣기/읽기 코스
- 문법 설명 중심 LMS
- 대규모 UGC 커뮤니티
- 실시간 인간 튜터 마켓플레이스
- 수천 개 콘텐츠 라이브러리 (주제 20–30개면 충분)
- 네이티브 액센트 점수 경쟁

## 5. 사용자

### 페르소나 A — 직장인
- 출퇴근 20분, 창피해서 학원 말하기가 부담
- 필요: 헤드셋 끼고 끝내는 10–20분 루틴
- 실패 조건: 수업처럼 길거나, 첫 화면이 강의면 이탈

### 페르소나 B — 중급 정체기
- 듣기만 늘고 말은 그대로
- 필요: 4-3-2, 청크 활성화, 반복 오류 추적
- 실패 조건: 새 영상만 추천하는 앱

### 페르소나 C — 초급
- 문장이 안 나옴
- 필요: 스크립트 청크 → 따라 말하기 → 빈칸 → 짧은 롤플레이
- 실패 조건: 바로 자유 대화

### 공통 제약
말할 상대 없음 / 틀리기 싫음 / 오늘 뭐 할지 모름

## 6. 정보 구조와 핵심 화면 (7개만)

1. **오늘 홈** — 남은 루틴, 큰 시작 버튼, 연속 일수
2. **쉐도잉 플레이어** — 10–20초 클립 반복
3. **말하기 세션** — 롤플레이 또는 4-3-2 또는 일상 중계
4. **피드백 + 재녹음** — 교정 최대 3개, 재발화 필수
5. **청크 덱** — 오늘 저장분 + 복습 대기
6. **진행** — 주간 말한 시간, 4주 비교 녹음
7. **설정** — 목표, 시간, 악센트, 자막, 계정, 음성 삭제

탭 구조 제안:
- 오늘
- 청크
- 진행
- 설정

## 7. 기능 요구사항

우선순위: P0 = MVP 필수, P1 = 출시 직후, P2 = 이후.  
P0만 구현해도 앱이 성립해야 한다.

### 7.1 온보딩·진단 — P0

**목적:** 설치 후 3분 안에 첫 발화를 끝낸다.

수집 항목:
- 목표: 일상 / 업무 / 여행 / 면접
- 가능 시간: 10 / 20 / 30분
- 관심 주제 최대 3개
- 자기 레벨: 초급 / 중급 / 중상급 (선택)
- 30초 자기소개 녹음 (건너뛰기 가능, 권장)

산출:
- 레벨 점수 대신 **오늘 할 루틴**을 보여 준다.
- 첫 세션은 쉬운 쉐도잉 60초로 바로 시작.

인수조건:
- [ ] 온보딩을 완료하지 않아도 게스트로 1세션 가능
- [ ] 온보딩 마지막 단계 전에 마이크 권한을 설명한다
- [ ] 온보딩 도중 최소 1회 말하기가 발생한다
- [ ] 선택한 목표·시간이 홈 루틴에 반영된다

### 7.2 데일리 루틴 엔진 — P0

기본 20분 구성:

| 순서 | 모듈 | 시간 | 필수 |
|---|---|---|---|
| 1 | 쉐도잉 워밍업 | 8–10분 | 필수 |
| 2 | 출력 과제 | 8–12분 | 필수 |
| 3 | 피드백 + 다시 말하기 | 3–5분 | 필수 |
| 4 | 청크 3개 저장 | 1분 | 필수 |

규칙:
- 어제 틀린 청크/오류가 오늘 워밍업에 1개 이상 재등장한다.
- 세션 중단 후 이어서 할 수 있다.
- 출력과 재발화를 안 하면 오늘 루틴 미완료다.
- 알림은 사용자가 고른 시간대에 1회.

인수조건:
- [ ] 홈에서 “오늘 시작” 한 번으로 루틴이 이어진다
- [ ] 중도 종료 후 재진입 시 마지막 단계부터 재개
- [ ] 재발화 생략 시 완료 체크가 되지 않는다
- [ ] 10/20/30분 선택 시 각 단계 시간이 비율대로 줄어든다

### 7.3 쉐도잉 모듈 — P0

클립:
- 길이 10–20초
- 레벨이거나 살짝 쉬운 재료
- 주제는 온보딩 관심사 우선
- v1 콘텐츠 수량: 주제 20–30개 × 클립 5–10개면 충분

모드 순서 (한 클립):
1. 듣기만
2. 동시 따라 말하기 (놓쳐도 멈추지 말라고 안내)
3. 같은 클립 3–5회
4. 오디오 끄고 혼자 말하기
5. 원본과 내 녹음 비교

기능:
- 배속 0.8–1.1x. 0.8 미만 금지 (운율 붕괴)
- 스크립트 표시 on/off
- 한국인 빈출 힌트: /f, v, θ, z, r, l/, 어말 자음, 강세

인수조건:
- [ ] 클립을 3회 반복하지 않고 다음으로 건너뛸 수 있다 (비권장, 가능은 함)
- [ ] 혼자 말하기 단계 녹음이 저장된다
- [ ] 스크립트 숨김 모드가 있다
- [ ] 재생과 녹음이 동시에 동작한다

콘텐츠 규칙:
- 대본은 자연스러운 구어
- 직역체 금지
- 한 클립에 학습 포인트 1개 (예: gonna 연결, 질문 억양)

### 7.4 출력 모듈 — P0

v1에서 출력 타입 2개를 넣는다.
- 필수: 롤플레이
- 필수: 일상 중계(혼잣말) 또는 4-3-2 중 하나
- 권장 MVP 조합: **롤플레이 + 4-3-2**
- 일상 중계는 시간이 없으면 P1

#### 7.4.1 롤플레이 — P0

상황 팩 (v1 최소 12개):
1. 카페 주문
2. 길 묻기
3. 스몰토크 (주말)
4. 자기소개
5. 회의에서 의견 말하기
6. 동의/부분 동의
7. 거절하기
8. 사과 + 이유
9. 일정 잡기
10. 모르는 말 되묻기
11. 가벼운 불만 전달
12. 면접: “자신을 소개하세요”

진행:
- AI가 한 턴 말한다
- 사용자가 음성으로 답한다
- 2–6턴
- 사용자가 질문을 오해하면 AI가 확인한다. 예: “Do you mean ___?”
- 종료 후 교정 3개 → 각 문장 재발화

인수조건:
- [ ] 무음 3초면 “한번 말해 보세요” 프롬프트
- [ ] 답변이 질문과 무관하면 교정 전에 의미를 재확인한다
- [ ] 세션 로그에 사용자 발화 텍스트가 남는다

#### 7.4.2 4-3-2 독백 — P0

- 초급: 2분 → 1.5분 → 1분
- 중급 이상: 4분 → 3분 → 2분
- 주제는 이미 아는 것 (주말, 일, 취미, 어제 한 일)
- 매회 녹음
- 안내 카피: “내용은 같고, 더 빨리, 덜 멈추세요”

인수조건:
- [ ] 3회차 모두 녹음되어야 완료
- [ ] 회차별 대략적 말하기 길이/침묵을 보여 준다 (정밀 채점 불필요)
- [ ] 주제를 직접 입력할 수 있다

#### 7.4.3 일상 중계 — P1

- 프롬프트: “지금 하는 일을 영어로 중계하세요”
- 막히면 청크 제안
- 제안된 청크를 문장에 넣어 다시 말해야 한다

### 7.5 피드백 엔진 — P0

피드백 3층. 한 세션에 층마다 억지로 채우지 말고, 합쳐서 최대 3개.

1. 의미: 질문에 답이 되었나. 상대가 이해할 수 있나.
2. 자연스러움: 직역 → 일상 청크.
3. 전달 방해 요소: 발음/문법 중 의미 전달을 깨는 것만.

피드백 카드 형식 (필수 필드):
- 내가 말한 것
- 문제 한 줄 (한국어)
- 더 자연스러운 영어 예문
- 따라 말하기 버튼
- 빈 화면에서 다시 말하기

금지:
- “Great job!”만 있는 카드
- 한 문장에 오류 7개 나열
- 오답을 맞는 답으로 이어가기

인수조건:
- [ ] 교정 항목마다 재녹음이 있다
- [ ] 3개 재발화를 마쳐야 세션 완료
- [ ] 동일 오류가 반복되면 오류 노트에 누적된다
- [ ] 예문은 학습자 레벨을 넘지 않는다

오류 노트:
- 최근 2주 반복 오류
- 홈 워밍업에 1개 삽입

### 7.6 청크 학습 — P0

학습 단위 예시:
- I'd like to make an appointment.
- What I'm trying to say is…
- Let me think for a second.
- Sorry, could you say that again?
- I see your point, but…
- It depends on the situation.

기능:
- 오늘 쓴 청크 / 못 쓴 청크 / 시스템 추천 청크
- 복습 순서: 듣기 → 따라 말하기 → 빈칸 말하기 → 상황 한 줄 사용
- 간격 반복: 말하기 성공이면 간격 증가, 실패면 다음날

인수조건:
- [ ] 세션 종료 시 청크를 3개 자동 또는 수동 저장
- [ ] 단어 단독 카드가 기본 뷰가 아니다
- [ ] 복습은 타이핑이 아니라 말하기가 기본

v1 시드 청크:
- 목표별 80–150개면 충분
- 일상 / 업무 / 여행 / 면접 태그

### 7.7 의사소통 전략 — P1 (콘텐츠로는 P0에 일부 포함)

명시적으로 가르칠 전략:
- 돌려 말하기 (circumlocution)
- 되묻기
- 시간 벌기
- 부분 이해 인정 후 확인
- 도움 요청

롤플레이 12개 중 최소 2개는 이 전략을 강제한다.
예: 상대가 일부러 빨리 말하면 `Sorry, could you say that again?`을 쓰게 한다.

### 7.8 진도·동기 — P0

표시:
- 오늘 완료 여부
- 연속 일수
- 이번 주 말한 시간
- 이번 주 완료 세션 수
- 주 1회 동일 프롬프트 재녹음 (“주말에 뭐 했어?”)

비교:
- 4주 전 vs 오늘 파형/텍스트를 나란히
- 정밀 발음 점수보다 멈춤·길이·사용자가 듣기에 편한 UX

스트릭 정책:
- 하루 빠졌다고 리셋 처벌을 과하게 하지 않는다
- 부드러운 리마인드
- “어제 못 한 3분 워밍업” 제안

인수조건:
- [ ] 말한 시간이 홈에 보인다
- [ ] 비교 녹음이 최소 1개 프롬프트로 동작한다
- [ ] 완료 기준이 재생 시간이 아니라 발화+재발화다

### 7.9 계정·권한·프라이버시 — P0

인수조건:

- [ ] 삭제 요청 시 로컬/서버 세션 오디오가 지워진다

## 8. 사용자 스토리와 인수조건

### US-01 첫 발화
As a 신규 사용자  
I want 설치하자마자 한 문장이라도 말하고  
So that 이 앱이 강의 앱이 아님을 안다.

완료: 온보딩 중 또는 직후 녹음 1회 성공.

### US-02 오늘 루틴
As a 직장인  
I want 홈에서 시작만 누르면 오늘의 말하기가 끝나고  
So that 무엇을 할지 고민하지 않는다.

완료: 쉐도잉 → 출력 → 재발화까지 한 플로우.

### US-03 교정 후 재발화
As a 중급 학습자  
I want 틀린 문장을 고친 버전으로 다시 말하고  
So that 실수를 반복 연습하지 않는다.

완료: 피드백 항목마다 재녹음 파일이 존재.

### US-04 청크
As a 초급 사용자  
I want 단어가 아니라 문장 덩어리를 복습하고  
So that 입이 바로 나온다.

완료: 카드에 구문이 있고 말하기 복습이 된다.

### US-05 변화 체감
As a 4주차 사용자  
I want 첫 주 녹음과 오늘 녹음을 비교하고  
So that 계속할 이유가 생긴다.

완료: 동일 프롬프트 2개 시점을 재생 비교 가능.

## 9. 카피 톤

- 짧고 단호하다. 자기계발 명언 남발 금지.

온보딩 핵심 문장:
“완벽해지면 말하는 게 아닙니다. 말하면서 늘립니다.”

## 11. 기술 요구 (구현 가이드)

확정 스택이 없으면 아래를 기본으로 제안하고 문서에 적는다.

- 클라이언트: Flutter 또는 React Native (둘 다 가능. 하나를 고르고 고정) → **1.1: 바닐라 HTML/CSS/JS 정적 PWA (빌드 없음), GitHub Pages 배포**
- 음성: 기기 마이크 → STT
- 대화/피드백: LLM
- 저장: 사용자 프로필, 세션, 청크, 오류 노트, 오디오 URL → **1.1: localStorage(프로필·세션·청크·오류 노트), IndexedDB(녹음). 서버 없음**
- 오디오: 원본 클립 + 사용자 녹음

### STT/피드백 파이프라인
1. 사용자 음성 녹음
2. STT 텍스트
3. 맥락(시나리오 질문, 목표, 레벨)과 함께 LLM에 전달
4. JSON으로 피드백 최대 3개 반환
5. 예문 TTS 또는 원어민 오디오 재생
6. 재녹음

### 피드백 JSON 스키마
```json
{
  "comprehensible": true,
  "on_topic": true,
  "items": [
    {
      "original": "I agree the idea.",
      "issue_ko": "동사 agree 뒤에 with가 빠졌습니다.",
      "improved": "I agree with the idea.",
      "layer": "naturalness",
      "severity": "medium"
    }
  ],
  "repair_question": null
}
```

`on_topic`이 false면 교정 전에 확인 질문을 한다.

### 품질 가드레일
- 예문 레벨이 사용자보다 두 단계 이상 높으면 안 된다.
- 비속어·성적인 롤플레이 기본 제공 금지.
- 미성년 대상 콘텐츠 없음. 이 앱은 성인 학습용.

### 성능
- 피드백 체감 3초 이내. 길면 스트리밍 또는 스켈레톤.
- 저가 안드로이드에서 녹음+재생 동시 가능해야 한다.
- 출퇴근 잡음을 고려해 너무 엄격한 침묵 감지 금지.

## 20. 개인용 적용 메모 (v1.1)

이 PRD는 여러 사용자를 위한 모바일 앱을 가정하지만, 실제 구현은 **한 사람(한국인 직장인 본인)** 이 쓰는 개인 도구다.
PRD 18의 업데이트 규칙에 따라, 원칙(2장)은 그대로 두고 아래 항목만 바꿨다. 코드와 이 메모가 다르면 이 메모가 기준이다.

### 20.1 플랫폼 (가정표 '플랫폼' 덮어씀)
- 네이티브 iOS/Android 앱 대신 **정적 웹 PWA**. 주소: https://aepiros33.github.io/english-speak/ (GitHub Pages, 공개 저장소).
- 백엔드 없음. 빌드 도구 없음(바닐라 JS). 휴대폰 브라우저에서 열고 '홈 화면에 추가'로 설치.
- 녹음: MediaRecorder (iPhone Safari는 audio/mp4, Chrome은 audio/webm 자동 선택). 녹음 파일은 IndexedDB에 저장, localStorage에는 넣지 않음.

### 20.2 계정·구독·프라이버시 (7.9 조정)
- 로그인·계정·게스트 모드·구독: **없음**.
- 유지: 첫 녹음 전 마이크 사용 설명, '음성·텍스트 기록 모두 삭제' 버튼(설정), 음성 학습 사용 안내.
- 학습 사용 안내 문구는 사실대로 쓴다: 녹음·기록은 기기에만 저장되고 이 앱은 목소리를 모델 학습에 쓰지 않는다. **단, AI 키를 넣으면 받아쓰기·롤플레이·피드백을 위해 녹음/텍스트가 사용자가 고른 AI 제공자에게 전송되고 그 제공자 정책을 따른다.** 특히 Gemini 무료 등급은 보낸 내용을 Google이 제품 개선에 쓸 수 있다고 설정 화면에 명시한다.
- 삭제 범위: 녹음 전부(IndexedDB), 받아쓰기, 대화 기록, 오류 노트, 내가 말한 문장. 청크와 복습 일정은 남긴다(별도 '처음부터 다시'로 전부 초기화 가능).

### 20.3 AI · 음성 구조 (11장 구체화)
- API 키는 사용자가 설정 → AI에서 직접 입력하고 **그 기기의 localStorage에만** 저장(`speakapp.key.<제공자>`). 저장소·백업 파일·서버 어디에도 없음. 커밋 전 키 패턴 검사.
- 제공자(모두 브라우저 CORS 확인 완료, Origin https://aepiros33.github.io):
  - Google Gemini — 기본. `gemini-3.5-flash-lite` (무료 등급 있음, 오디오 입력으로 받아쓰기까지 한 번에).
  - OpenAI — 대화/피드백 `gpt-6-luna`, 받아쓰기 `gpt-transcribe` (/v1/audio/transcriptions).
  - xAI — 대화/피드백 `grok-4.20-0309-non-reasoning`, 받아쓰기 xAI STT (/v1/stt).
  - 모델 ID는 설정에서 바꿀 수 있다.
- 받아쓰기 순서: 녹음 → 제공자 STT → (실패하거나 키가 없으면) 브라우저 Web Speech API(iPhone 제외) → 없으면 텍스트 없이 녹음만.
- 롤플레이·피드백은 JSON 출력(11장 스키마 그대로)으로 받고 앱에서 다시 검증(최대 3개, 칭찬만 있는 항목 제거, 잘못된 값 보정, 망가진 응답은 오류 화면).
- 피드백 대기 중 스켈레톤 표시.
- **키가 없을 때**: 쉐도잉, 4-3-2(녹음·길이·멈춤), 청크 복습(브라우저 음성 인식 또는 자가 채점)은 그대로 동작. 롤플레이는 '설정에서 AI 키를 넣으면 열려요' 잠금 상태로 보여 준다(가짜 버튼 없음).
- **실제 제공자 검증 (v2.1, 2026-09-25)**: 실제 Gemini 키로 받아쓰기(webm·m4a)·롤플레이 2개(일정 잡기, 길 묻기)·피드백·청크 제안을 확인. 체감 지연은 롤플레이 약 2초(받아쓰기+턴), 피드백 약 1초로 3초 목표 안. 가끔 멈추는 요청 → 첫 시도 짧게 끊고 1회 재시도. 무료 등급 분당 15회 → 429면 대기 후 1회 재시도·한국어 안내.
- 피드백 확인 질문은 on_topic=false **또는** comprehensible=false일 때 먼저 묻는다(실제 응답에서 '뜻이 안 통함 + 주제는 맞음' 패턴 확인).
- 롤플레이 프롬프트: 앞서 말한 사실(요일·시간·장소·방향)을 바꾸거나 빼지 않기, 다시 말해 달라고 하면 같은 내용을 천천히.
- 소리: 녹음 후 마이크 완전 해제(iOS 수화부 문제), 녹음 재생 Web Audio 부스트(기본 2×)+리미터, 쉐도잉 음원 AI 음성(Gemini TTS, 선택·캐시). TTS 무료 등급은 분당 3문장이라 롤플레이·복습에는 쓰지 않음.

### 20.4 PRD와 다르게 구현한 점 (의도적 편차)
1. **쉐도잉 음원 = TTS**: 원어민 녹음 파일이 없으므로 클립은 스크립트이고 기기 음성합성(speechSynthesis)으로 읽는다. 억양 US/UK는 기기에 있는 음성 중에서 고른다. 속도는 0.8–1.1만.
2. **클립 60개** (PRD 권장 약 100): 양보다 질. 일상 28 · 업무 16 · 여행 9 · 면접 7, 10–14초, 10장 메타데이터 + 학습 포인트 1개 + 한국어 발음 힌트.
3. **키 없는 날의 피드백 = 셀프 교정**: AI 교정 대신, 오늘 상황에 맞는 청크 3개를 '빈 화면에서 다시 말하기'(녹음)로 반드시 말해야 완료. 원칙(교정 + 재발화 = 완료 조건)은 유지.
4. **4-3-2 시간**: 20·30분 루틴은 PRD 그대로(초급 2→1.5→1분, 중급+ 4→3→2분). 10분 루틴은 전체 시간에 맞춰 절반(중급+ 2→1.5→1분, 초급 1→0.75→0.5분).
5. **루틴 분량 스케일**: 쉐도잉 클립 수 2/3/5, 반복 3/4/5회, 롤플레이 3/4/6턴 (10/20/30분). 단계 목표 시간은 20분 기준 8/8/3/1분을 비례 조정.
6. **복습 간격**: SM-2 계열 유지, 단 PRD대로 '실패 → 다음 날', '성공 → 간격 증가'(분 단위 재학습 단계 없음). v1의 '한국어 보고 먼저 떠올리기' 순서 대신 PRD 순서(듣기 → 따라 말하기 → 빈칸 말하기 → 상황 한 줄)로 바꿨다.
7. **'말한 시간'**: 녹음에서 실제로 소리가 난 시간(음량 분석)만 센다. 청크 복습(브라우저 음성 인식)은 녹음하지 않으므로 포함하지 않는다.
8. **부드러운 스트릭**: 하루 빠지면 다음 날 홈에 '어제 못 한 3분 워밍업'. 끝내면 어제가 이어진 것으로 계산.
9. **기존 v1 데이터**: 삭제하지 않고 이전(마이그레이션). 카드·SRS 진행·나의 문장·반응시간·학습 로그·설정을 그대로 옮기고, v1 원본(`speakapp.v1`)도 백업으로 남긴다. 이후 v2 데이터는 `speakapp.v2`.
10. **'왜 이렇게?' 페이지**: 설정 안의 하위 페이지로 이동(4개 탭: 오늘 · 청크 · 진행 · 설정).
11. **P1/P2 미구현**: 일상 중계(7.4.3), 의사소통 전략 별도 모듈(7.7 — 롤플레이 2개와 힌트로 일부 포함), 소셜·튜터(7.10), 오프라인 클립 프리패치.

6. 앱 이름 → '말하기 루틴'.
